Help with DOYOURWORK

For iPhone, iPad and Android. The app works the same way on all three.

What it is

A chore scoreboard for your household. Everyone picks about 25 minutes of chores a day and checks them off, an admin (usually a parent) approves, and points, streaks and a weekly winner follow.

Private by design: no accounts, no sign-up, and nothing ever leaves your device. The privacy policy has the detail.

The app is coming soon to the App Store and Google Play. To try it early, join the beta.

Getting started

  1. Open the app and tap Set up this device.
  2. Type your name and choose an admin code. The code is what approves chores, so keep it from the players.
  3. Add the people who'll be doing chores.
  4. Tap Use the starter list, or write or say your own chores and the app sorts them into a list.

After that, each player taps their name, picks chores up to 25 minutes, checks them off and sends the card for approval. An admin opens Admin with their code and says yes or no to each one.

Common questions

I forgot my admin code.

The code is kept only on your device, so nobody, including us, can look it up or reset it. If another person in your household is an admin, they can open Admin, tap Edit next to your name and give you a new code. If you turned on face or fingerprint unlock for Admin, that opens it too. Otherwise the way back in is to delete the app and set up a new scoreboard, which loses the points so far. Making a second person an admin now is the best protection.

Can we each use our own phone?

Not yet. This version is one shared scoreboard on one phone or tablet. Sharing a scoreboard between a household's devices is planned.

We got a new phone. How do we move the scoreboard?

On the old one, open Admin and tap Save a backup. It makes a file that you keep wherever you like. On the new one, set up the app, open Admin and restore from that file. It works between iPhone and Android in either direction.

How do I change the chores?

Open Admin and look under chores. Add chores takes them written or spoken, and Edit next to a chore changes its name or minutes, or removes it.

Why does a chore take longer than it did?

A chore that goes undone for a few days takes longer the next time it's picked, and moves up the list. Doing it resets it.

Someone else took the chore I wanted.

Each chore can be done by one person a day. It's back tomorrow.

How do I start again from nothing?

Open Admin and tap Erase everything. Save a backup first if you might want the scores back.
