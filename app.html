SUPPORT

What it is

A chore scoreboard for your household. Everyone picks about 25 minutes of chores a day and checks them off, an admin (usually a parent) approves, and points, streaks and a weekly winner follow.

Private by design: no accounts, no sign-up, and nothing ever leaves your device. See the privacy policy.

Getting started

  • Open the app and tap set up this device
  • Type your name and choose an admin code: this is what approves chores
  • Add the people who'll be doing chores
  • Use the starter list of chores, or write or say your own and the app sorts them into a list

Common questions

I forgot my admin code. The code is kept only on your device, so nobody, including us, can look it up or reset it. If another person in your household is an admin, they can open the admin area and give you a new code under players → edit. If you turned on Face ID or Touch ID for the admin area, that opens it too. Otherwise the way back in is to delete the app and set up a new scoreboard, which loses the points so far. Making a second person an admin now is the best protection.

Can we each use our own phone? Not yet. This version is one shared scoreboard on one iPhone or iPad. Sharing between a household's devices is planned.

How do I change the chores? Admin → chores. You can add chores by writing or saying them, and edit or remove any chore.

Why does a chore take longer than it did? A chore that goes undone for a few days takes longer the next time it's picked, and moves up the list. Doing it resets it.

Someone else took the chore I wanted. Each chore can be done by one person a day. It's back tomorrow.

How do I start again from nothing? Admin → device → erase everything.
